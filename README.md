# Cumpleaños de Lesly

## Publicación en GitHub Pages
1. Sube `index.html` y `portada.jpg` a la raíz del repositorio.
2. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. En `index.html`, reemplaza `TU-USUARIO` y `TU-REPOSITORIO` en las etiquetas `og:image` y `twitter:image` por tu usuario y repositorio reales de GitHub.
4. Comparte el enlace público de GitHub Pages.

La imagen `portada.jpg` está preparada en formato 1200 × 630 para vistas previas al compartir. WhatsApp y otras plataformas pueden tardar en actualizar la vista previa por caché. Instagram no siempre muestra tarjetas de enlace en mensajes directos.
